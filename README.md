# ink_esp

这是一个基于 ESP-IDF 的 ESP32-C3 墨水屏联调工程。

## 当前分支定位

当前分支是 `1.0.2-refreshable`。

这个分支用于保留首次点亮、首次确认“屏幕可以刷新”的 `1.0.2` 代码基线，方便后续和新的驱动开发版本进行对比。

## 本分支用途

- 回看首次点亮时的代码状态
- 保留最早验证通过的可刷新版本
- 作为后续驱动研究和精细化移植的对照基线

## 对应关系

- `1.0.2-refreshable`
  首次点亮、可刷新的 `1.0.2` 基线分支

- `development`
  最新开发分支，包含后续更精细的 `Z19c` 驱动整理、日志优化和官方流程对齐工作

## 使用建议

- 如果要继续开发，请切换到 `development`
- 如果要回看首次点亮版本，请停留在 `1.0.2-refreshable`
