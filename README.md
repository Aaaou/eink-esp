# ink_esp

这是一个基于 ESP-IDF 的 ESP32-C3 墨水屏联调工程，当前重点是 2.13 寸三色墨水屏与板级音频、I2C、SPI、IO 扩展路径的联合验证。

## 分支说明

### `development`

最新开发分支。  
这个分支用于继续推进当前更精细的驱动研究与移植工作，包含我们后续对官方 `GxEPD2_213_Z19c` 路径所做的细化、日志整理、等待时序对齐和驱动结构优化。

适用场景：

- 继续开发与调试
- 对齐官方 Arduino / GxEPD2 行为
- 增加更详细的日志与验证路径
- 做后续驱动收敛和稳定性优化

### `1.0.2-refreshable`

首次点亮、可刷新的历史基线分支。  
这个分支对应首次确认“屏幕可以刷新”的 `1.0.2` 代码基线，主要用于保留最早验证通过的版本，避免后续开发覆盖这一参考状态。

适用场景：

- 回看首次点亮时的代码状态
- 与后续开发版做差异比对
- 确认哪些改动属于后续精细化调整

## 当前约定

- 若要继续开发，请优先在 `development` 分支工作。
- 若要回看首次点亮状态，请切换到 `1.0.2-refreshable` 分支。
- 若后续确认某个版本再次稳定点亮，建议继续用独立分支或 tag 固化，避免“可刷新版本”被开发中的实验改动混入。
